## 购买机场前需要知道

1. **当前表现≠未来表现**：机场本质是服务器+线路，线路随时可能变化，别把它当「一次性买断的稳定品」。
2. **线路比流量更重要**：专线（IEPL/IPLC）延迟低、波动小；中转性价比高。判断好坏要结合晚高峰、丢包与实际使用，而不是只看单价流量。
3. **不要一次买太多年**：谁也不知道机场什么时候跑路，优先月付 / 短周期，稳定了再续。
4. **一定准备备用机场**：高强度使用建议同时备 2 家，避免主力失联时无网可用。
5. **不推荐超便宜机场**：极低价常伴随超售、复用线路、高返佣割韭菜；便宜好用往往不可兼得。按**每 GB 单价 × 稳定性**综合判断。

> 更完整的选购与避坑，见 [性价比机场](https://tizinodes.com/value) 与 [避免机场跑路造成损失](https://tizinodes.com/posts/avoid-airport-shutdown-loss)。

## FAQ

**哪种机场最稳定？** 一般价格高、线路多的更稳，因为老板更舍得投入上游线路；便宜机场预算有限，常在线路上节省。

**为什么推荐准备多个机场？** 机场本质是服务器，必然有挂的时候，建议常备 2 家以上，避免失联。

**IEPL/IPLC 一定比中转好吗？** 专线通常更稳、延迟更低，但更贵；中转性价比高。真正质量要看晚高峰与实际使用，不能只看名称。

**延迟低就是速度快吗？** 不一定。延迟主要和物理距离/入口占用有关，速度看带宽与拥堵；两者是不同指标。

**官网打不开是不是跑路了？** 不一定，防火墙常污染机场官网，也可能是临时故障。判断失联请结合 [机场状态](https://tizinodes.com/status) 与 [风险预警](https://tizinodes.com/risk)。
